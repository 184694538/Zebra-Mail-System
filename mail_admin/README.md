# 斑马邮箱（ZebraMail）

> 基于 **hMailServer** 的开源邮箱管理与网页邮箱系统，让邮箱域名、账户、WebMail 和日常运维集中在一个 Web 界面中。

斑马邮箱（ZebraMail）主要面向使用 hMailServer 搭建邮件服务的用户。项目以 **ThinkPHP 8** 为 Web 应用框架，配合 **PHP** 和 **MySQL / MariaDB**，提供邮箱管理、网页收发邮件、系统设置及数据库维护等功能。

**定位说明：** 斑马邮箱是 hMailServer 的 Web 管理与使用界面，**不替代 hMailServer 邮件服务器本身**。实际邮件收发、SMTP / IMAP 等服务仍由对应邮件服务组件提供。

## ✨ 主要功能

| 模块 | 功能说明 |
| --- | --- |
| 域名管理 | 集中查看和管理邮件域名 |
| 邮箱账户 | 管理邮箱账户及相关配置 |
| WebMail | 通过浏览器访问网页邮箱 |
| 系统管理 | 管理系统设置及相关接口功能 |
| API 文档 | 查看项目提供的接口说明 |
| 数据库备份与恢复 | 根据需要选择不同范围的数据备份和恢复 |
| 数据库维护 | 提供数据库冗余数据清理等维护操作 |

> 具体功能、可用入口和操作权限以所使用版本的实际代码与页面为准。

## 🛠️ 技术栈

- **邮件服务：** hMailServer（项目主要围绕 hMailServer 6.3 的使用场景）
- **后端框架：** ThinkPHP 8 / PHP
- **数据库：** MySQL 或 MariaDB
- **前端：** HTML、CSS、JavaScript
- **Web 服务：** 按项目部署环境配置 Nginx 或其他兼容的 Web 服务器

项目依赖和具体运行环境要求，请以对应版本中的配置文件、依赖清单及安装教程为准。

## 🚀 部署概览

1. **准备邮件服务。** 安装并正确配置 hMailServer，确认邮件域名、账户及必要的邮件协议服务能够正常工作。
2. **准备 Web 环境。** 安装符合项目依赖要求的 PHP、MySQL / MariaDB 与 Web 服务器。
3. **部署项目代码。** 将本项目代码放入网站目录，按项目实际依赖清单安装所需组件。
4. **配置数据库连接。** 按项目提供的配置方式填写数据库地址、数据库名和账户信息；不要将真实密码提交到 Git 仓库。
5. **配置站点入口。** 按 ThinkPHP 8 及项目实际目录结构设置 Web 根目录、路由和必要的读写权限。
6. **完成初始化和验证。** 根据安装教程执行初始化步骤，并分别验证管理后台、WebMail、域名及账户管理等功能。

**注意：** 以上为部署流程概览，不是可直接执行的完整安装脚本；首次部署前请阅读与当前发布版本对应的安装文档。不要在生产环境直接套用未经核对的示例配置。

## 💾 数据库备份与维护

项目的数据库维护功能涉及不同的数据保存范围，操作前应明确各类型备份的区别。

| 操作 | 数据范围 / 注意事项 |
| --- | --- |
| 系统模板备份 | 侧重系统表结构与系统设置 |
| 简易备份 | 在系统模板基础上，额外包含域名、邮箱账户及 IMAP 文件夹相关数据 |
| 数据库全量备份 | 包含数据库中的表和记录，**不等于**备份磁盘上的实际邮件文件 |
| 冗余数据清理 | 保留与简易备份相同范围的数据；其他指定表可能通过 **TRUNCATE** 清空 |

**重要警告：** 数据库清理可能造成不可恢复的数据丢失。相关清理流程**不会自动创建全量备份、不会自动停止邮件服务，也不会删除磁盘邮件文件**。请先手动做好数据库及邮件文件的独立备份，并在维护窗口确认影响范围后再执行。备份、恢复与清理操作应仅授予可信管理员。
