API 接口文档

02读取邮件（需要密码）

GET /MailApi/read_email 返回 HTML 页面

使用指定邮箱账户和密码连接邮件服务器，读取一封邮件。默认读取收件箱中最新一封邮件。

请求参数

参数必填默认值说明
key是—读取邮件密钥：read_email_key
username是—完整邮箱地址
password是—邮箱登录密码
server_ip否127.0.0.1邮件服务器 IP 或主机名
port否143支持 143（IMAP STARTTLS）、993（IMAP SSL/TLS）、110（POP3）、995（POP3 SSL/TLS）
mbox_id否0邮件序号；0 表示读取当前最后一封邮件
delete否0设为 1 时尝试删除读取的邮件；仅 IMAP 端口支持，且服务器需支持 UIDPLUS
beautify否0设为 1 时打开美化收件箱页面，见下方说明

调用示例


                    
                

                

                    美化模式：添加 beautify=1 后显示只读收件箱，按「API 管理」中设置的全局数量限制展示邮件。该模式忽略 mbox_id 和 delete，不会自动删除邮件；未提供账户或密码时会显示输入页面。
                

                
普通读取模式返回 HTML 邮件内容页面，不是 JSON 数据。

            


            

                
03读取邮件（免密码）

                

                    GET
                    /MailApi/read_email2
                    返回 HTML 页面
                

                
通过系统保存的邮箱原始密码连接本机 hMailServer。调用方只需要传入邮箱账户，不需要传入邮箱密码。

                
请求参数

                

                    

                        
参数必填默认值说明

                        
                            
key是—免密码读取密钥：read_email_key2

                            
username是*—完整邮箱地址；普通读取模式必填

                            
port否143支持 143、993、110、995；连接目标固定为本机 127.0.0.1

                            
mbox_id否0邮件序号；0 表示读取当前最后一封邮件

                            
delete否0设为 1 时尝试删除读取的邮件；仅 IMAP 端口支持，且服务器需支持 UIDPLUS

                            
beautify否0设为 1 时打开只读美化收件箱；可不传 username 先打开输入页面

                        
                    

                

                
调用示例

                

                    

                    
                

                

                    使用条件：邮箱必须是已启用的普通邮箱，并且系统中已保存该邮箱的原始密码。未保存原始密码的旧账户无法使用此接口。该接口不接受 server_ip 参数，固定连接本机邮件服务。
                

            


            

                
04批量删除邮件

                

                    GET
                    /MailApi/delete_emails
                    返回 JSON
                    高风险操作
                

                
连接指定邮箱服务器，删除该邮箱 INBOX 中的全部邮件。此操作不可恢复，请务必确认邮箱账户和参数。

                
请求参数

                

                    

                        
参数必填默认值说明

                        
                            
key是—删除邮件密钥：delete_emails_key

                            
username是—完整邮箱地址

                            
password是—邮箱登录密码

                            
server_ip否127.0.0.1邮件服务器 IP 或主机名

                            
port否143仅支持 IMAP 143（STARTTLS）或 993（SSL/TLS）

                        
                    

                

                
调用示例

                

                    

                    
                

                
成功响应

                
{
  "status": true,
  "message": "已删除 12 封邮件"
}

                

                    重要：该接口会删除 INBOX 中的全部邮件，不是只删除某一封。接口仅支持 IMAP 143/993，不支持 POP3。请勿将删除密钥放在公开网页或客户端代码中。

06响应与错误说明

                

                    

                        
情况返回内容处理建议

                        
                            
API 总开关关闭HTTP 403；提示邮件 API 已由管理员关闭在后台「API 管理」中启用 API

                            
密钥错误读取接口返回错误 HTML；JSON 接口返回错误信息检查密钥是否匹配，必要时重新生成

                            
邮箱账户或密码错误显示连接或认证失败信息检查邮箱账户、密码、服务器地址和端口

                            
没有邮件提示无邮件或返回对应 JSON 状态确认 INBOX 中存在邮件

                            
查询不到域名JSON 中返回 code: 404确认系统已配置域名

                            
删除接口端口不支持JSON 错误信息将端口改为 143 或 993

                        
                    

                

                
读取邮件接口输出 HTML；删除邮件和查询域名接口输出 JSON。调用端应根据对应接口的返回类型处理响应。

            


            

                
07安全注意事项

                
    
                    
  • 正式环境请使用 HTTPS，避免密钥和邮箱凭据在网络中明文传输。
    • 
                    
  • 密钥具有实际操作权限，请勿发布到公开网页、公开代码仓库或群聊中。
    • 
                    
  • 当前示例使用 URL 查询参数传递密钥和邮箱凭据，可能被浏览器历史、Web 服务器访问日志等记录；请勿在公共设备上调用，并按需清理日志。
    • 
                    
  • delete_emails 会删除整个 INBOX，请在服务端严格限制调用权限，并先确认目标邮箱。
    • 
                    
  • 如果怀疑密钥泄露，请在「API 管理」页面重置对应密钥。
    •
